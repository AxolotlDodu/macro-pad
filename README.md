Projet du macro pad.

### Pour Sonar :
Nom des channels :

 - Master = master
 - Game = game
 - Chat = chatRender
 - Média = media
 - Aux = aux
 - Micro = chatCapture

Fontions implémentées :

- Volume +/- channels
- Mute/Unmute channels
- Change device (input/output)

On peut avoir toutes les inputs/outputs ici :

- http://127.0.0.1:64409/audioDevices

### Pour discord :

Fonctions implémentées :
 - mute
 - deafen
